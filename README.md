# 🎵 Яндекс Музыка для Nintendo Switch

Нативный homebrew-клиент Яндекс Музыки для консоли **Nintendo Switch**, написанный на C++17 с использованием **devkitPro (libnx)**, **SDL2** и неофициального **Yandex Music API**.

![App Icon](icon.jpg)

---

## 🌟 Возможности

- 🔑 **Авторизация**: Ввод OAuth-токена через встроенную экранную клавиатуру Switch (Swkbd) или сохранение в файл `sdmc:/switch/yandex-music/token.txt`.
- 📚 **Моя музыка**: Просмотр ваших плейлистов и треков «Мне нравится».
- 🔍 **Поиск**: Полноценный поиск по трекам, альбомам и артистам с удобными вкладками.
- 💿 **Альбомы и плейлисты**: Просмотр списков треков, длительности, исполнителей.
- 🎶 **Аудио-плеер**: Воспроизведение потокового аудио в формате MP3 (высокий битрейт до 320 kbps) через `SDL2_mixer` с поддержкой аппаратного аудиовыхода Switch (48 кГц).
- 🎛 **Фоновый плеер**: Нижняя панель плеера с прогресс-баром, таймингом и управлением очередью.
- 🎮 **Полная поддержка кнопок и джойконов**: Интуитивное управление геймпадом.
- ❤️ **Лайки**: Добавление треков в «Мне нравится» по нажатию кнопки **[Y]**.

## 🎮 Управление (Геймпад Switch)

| Кнопка | Действие |
|---|---|
| **D-Pad / Left Stick** | Навигация по спискам и меню (Вверх / Вниз) |
| **[A]** | Выбрать элемент / Запустить трек / Ввести токен |
| **[B]** | Назад / Отмена |
| **[X]** | Открыть поиск (с любого экрана библиотеки) |
| **[Y]** | Поставить лайк треку / Выйти из аккаунта (на главном экране) |
| **[L] / [R]** | Переключение вкладок |
| **[-] (Minus)** | Пауза / Возобновление воспроизведения |
| **[ZL]** | Предыдущий трек |
| **[ZR]** | Следующий трек |
| **[+] (Plus)** | Выход из приложения |

## 🔑 Как получить OAuth-токен Яндекс Музыки

Для работы приложения необходим OAuth-токен аккаунта Яндекс (желательно с активной подпиской Яндекс Плюс):

### Способ 1: Через браузер
1. Откройте в браузере ссылку авторизации:
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
   ```
2. Разрешите доступ.
3. В адресной строке после `#access_token=` скопируйте ваш токен.

### Способ 2: Через DevTools
1. Войдите на сайт [music.yandex.ru](https://music.yandex.ru).
2. Нажмите **F12** (Инструменты разработчика) -> вкладка **Сеть (Network)**.
3. Найдите любой запрос к `api.music.yandex.net`.
4. В заголовках запроса найдите `Authorization: OAuth <ВАШ_ТОКЕН>`.

> 💡 **Совет:** Вы можете заранее сохранить полученный токен в текстовый файл на карте памяти:  
> `sdmc:/switch/yandex-music/token.txt` — приложение подхватит его автоматически!

## 🛠 Сборка из исходников

### Требования
- Установленный инструментарий **devkitPro** с пакетом `switch-dev`
- Пакеты библиотек для Nintendo Switch (устанавливаются через `dkp-pacman`):
```bash
dkp-pacman -S switch-dev \
              switch-sdl2 \
              switch-sdl2_mixer \
              switch-sdl2_ttf \
              switch-sdl2_image \
              switch-sdl2_gfx \
              switch-curl \
              switch-mbedtls \
              switch-mpg123 \
              switch-flac \
              switch-libvorbisidec \
              switch-opusfile \
              switch-freetype \
              switch-libpng \
              switch-libjpeg-turbo
```

### Команда сборки
В корневой папке проекта выполните:
```bash
make
```
После успешной компиляции в корне проекта появится исполняемый файл **`yandex-music.nro`**.

---

## 📦 Установка на консоль

1. Скопируйте файл `yandex-music.nro` на MicroSD-карту консоли по пути:
   ```
   /switch/yandex-music/yandex-music.nro
   ```
2. Вставьте MicroSD в Nintendo Switch и запустите Homebrew Menu (через альбом или тайтл-оверрайд).
3. Найдите в списке **Yandex Music** и запустите!
